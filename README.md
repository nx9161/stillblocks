# Stillblocks

A calm, beautifully crafted keyboard-first falling-blocks arcade game.

> **Status:** early concept — the vision and name are set; the game itself is still to be built.

## Vision

Falling-blocks, reimagined as a meditative experience: keyboard-first controls, clean visuals, no clutter. Think Tetris, but designed to lower your heart rate.
